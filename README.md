# えいごペット 🥚

子供向けの **英単語学習 × たまごっち風育成** Webアプリです。
英単語クイズに正解してキャラにごはんをあげ、毎日続けるほどキャラが育って進化します。

**▶ アプリを開く: https://gaogao999.github.io/eigo-pet/**

---

## 特徴

### 英単語クイズ
- 英検 **準2級・2級**（合計 約3,700語）から4択で出題
- **ふりがな付き**：日本語訳はすべてふりがな（ひらがな）表示。漢字が読めなくてもOK
- **音声読み上げ**：端末の英語音声で発音（🔊きく）。せってい→きせかえ で**こえとはやさを変更**できます
  - 端末に入っている英語音声を**すべて**表示し、**品質の高い順**に並べます（拡張／Premium／Neural →ネットワーク音声→定番の聞きやすい声）。日本語音声やネタ音声（Zarvox・Bahh など）は除外・降格
  - **アクセント表示つき**（アメリカ／イギリス／オーストラリア／インド）
  - **より自然な声にする方法**：iPhone/iPadの **設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語** で「**拡張**」「Premium」の声を無料ダウンロードすると、アプリ側に**（高品質）**として現れ、自動でそちらが選ばれます（アプリ内にも案内を表示）
  - **注意**：iOS Safari は端末に入っている声をすべてWebに公開するとは限りません（拡張版を入れても出てこない場合があります）。せってい→データ の「**この たんまつの こえを ぜんぶ 見る**」で、端末が実際に返している声と、アプリが採用/除外した内訳を確認できます
  - 声の一覧が**遅れて届く端末**にも対応（届くまで数秒間ポーリングし、届いたら自動で選び直します）
- **やさしいいみ**：日本語の選択肢を**長押し**すると、子供向けのかんたんな説明を表示
- **わからないボタン**：押すと答え（正解）を表示。その単語は復習にまわります

### 学習の仕組み（おぼえる → わすれない）
論文の知見にもとづく**間隔反復（SRS）**で出題します。

- **1回のべんきょうは5問**。内訳は「**復習の期限がきた語を最大3問**（期限がふるい順）＋ **のこりは新しい語**」
- **正解すると次の出題が 1→3→7→14→30→60日後** と広がっていく。**まちがえるとその日にもどる**（間隔リセット）
- **「おぼえた」語も引退させず、間隔をのばして出しつづける**
- **ふりがな付き**：日本語訳はすべてふりがな（ひらがな）表示。漢字が読めなくてもOK
- **しんちょくは2段階**で表示（SRSにすると「おぼえた」が付くまで最短4日かかり、初日にバーが動かないため）
  - 🌱 **おぼえかけ**＝1回でも正解した語（**初日から伸びる**・うすい緑）
  - ⭐ **おぼえた**＝3回正解して間隔が7日以上になった語（濃い緑）
  - **「きょう 🌱+N ⭐+N」**＝その日ふえた数。累計が動きにくい日でも毎日必ず動く
- **すでに知っている語を自動で見きわめ**、復習の枠を無駄にしない
  - **ヒントも音声も使わず、その子にしては速く**正解した語は「もう知っている」サインとみなす
  - 初回からそっこう正解 → いきなり**間隔14日**／それが**2回続けば60日**（まぐれ当たりの先送りを抑える安全設計）
  - 「速い」の基準は固定値ではなく、**その子自身の回答時間の分布**（正解のうち速いほうから40%）から出題形式ごとに算出。データが20件たまるまでは既定値
  - まちがえたら通常どおり間隔リセット
- 出題形式は 英→日4択 1/2・スペル入力 1/4・日→英4択 1/4。**初めて見る語にはスペル入力を出さない**（初見の綴り入力はほぼ失敗し、検索練習として成立しないため）
- 4択のダミーは**同じ品詞**から優先して選ぶ

<details><summary>根拠にした研究</summary>

- **Karpicke & Roediger (2008)** — 正解できるようになった語を「再学習のみ」か「テスト継続」かで比較。1週間後の再生率は**再学習36% / テスト継続80%**。→ おぼえた語も出題しつづける設計にした
- **Cepeda et al. (2008)**（1,350人以上・最長1年後テスト）— 最適な復習間隔は**目標保持期間の約10〜20%**（1年後なら5〜10%）。→ 1→3→7→14→30→60日の階段
- **Nakata (2015)**, **Nakata & Webb (2016)** — 効果が大きいのは「**間隔の量**」で、拡張間隔 vs 均等間隔の差や、一度に学ぶ語数の差は小さい。→ 5問/回はそのままに、日をまたぐ間隔を導入
- **Nakata (2016)** — 綴りの産出には再生形式（スペル入力）、綴り不要なら認識形式（4択）が効率的。→ 3形式のミックスを維持

</details>

### たまごっち風の育成（時間ベースのライフサイクル）
- 成長段階：**タマゴ → ベビー → キッズ → ヤング → アダルト**
- 各進化は「**時間の経過＋その日の勉強**」の両方で成立（勉強しないと進化しない）
  - ベビー1時間・キッズ1日・ヤング2日 → アダルトはおよそ3日目
- **寿命 10〜15日**：毎日の勉強・お世話で延び、放置・病気放置で縮む
- **毎日のお世話が必要**：おなかが空っぽのまま／病気のまま**約2日**ほうっておくと、寿命をまたずに**お別れ**になってしまう（早めにごはん・おくすりを。危なくなると警告が出ます）
- 寿命がくると **お別れ → 新しいタマゴで再スタート**（学習の進捗・着せ替えは引き継ぎ、育てた子は「けいふ」に記録）
- 各成長段階は **オリジナルのドット絵キャラ**（PNG）で表示。系譜は **タマゴ → ベビー（ぴよっち）→ キッズ（ちびっち）→ ヤング4種**（お世話ランク ⭐◎○△）**→ アダルト**
- ヤングの姿は**確率制**（ランダム性は高め）：目標達成日数で決まる「本命ランク」が**約34〜39%**、となりのランク約24〜28%、遠いほど低確率。がんばるほど良いランクが出やすいが、**同じ育て方でも毎回ちがう子になる**（完全ランダムなら各25%）
- **アダルトへの進化は「ヤングの姿」で決まる**：各ヤングは **専用3種＋となりのヤングと共有する2種×2組＝7種**のどれかへ進化（となり合うヤング同士が輪でつながる構造）
  - すいすいたま（⭐）→ みらたま・ぴこぴこ・にんじゃ ＋ ぷくたま/ぴねむ（◎と共有）＋ めらめら/くろだま（△と共有）
  - しろころ（◎）→ はがた・ばぶたま・うらら ＋ ぷくたま/ぴねむ（⭐と共有）＋ めっこ/ちゃめ（○と共有）
  - もふたま（○）→ うさたま・どきどき・たまぱ ＋ めっこ/ちゃめ（◎と共有）＋ もぐもぐ/ぴな（△と共有）
  - くさたま（△）→ かぶら・ぴよたま・くちぱ ＋ もぐもぐ/ぴな（○と共有）＋ めらめら/くろだま（⭐と共有）
  - **★レア6種**（げーむ・がくがく・ねむね・おひさま・はんば・おばけ）は**どのヤングからでも**。**特殊条件**（下記）を満たすと出現率が 8%→**35%** に上がり、その条件に対応する子が出やすい
- 全20種＋★レア6種＝**計26種**を図鑑にあつめられます
- **26種すべてに「こだわり条件」**（育て方で出やすくなる／**確定ではない**）。同じヤングから進化する7種は**すべて別条件**なので、狙って育て分けられます
  - 条件を満たしたときの出やすさ：**そのヤング専用の子は 約67%**（重み×12）、**ふたつのヤングから なれる共有の子は 約45%**（重み×5）、★レアは約71%。条件なしなら各14%
  - 一般条件（通常20種）：ごきげん屋（ごきげん80+）／おぎょうぎ◎（すなおさ70+）／やんちゃ（すなおさ30-）／まんぷく（おなか80+）／せわ上手（せわミス0）／がんばりや（50問正解）／ずぼら（せわミス3+）
  - 特殊条件（★レア6種）：おもい子（体重25+）／かるい子（体重5）／あそびずき（ゲーム50回）／べんきょうか（100問正解）／ねぼすけ（すいみん10回）／まいにちさん（7日連続）
- ステータス：おなか・ごきげん・**すなおさ**・体重
- **すなおさ**：あそぶ（なつく）と上がり、**わがままサイン**が出たときに**しつけ**ボタンで対応すると上がる（タイミングを外すとごきげんが下がる）
- **ごはん**（えさ1）：おなか+20・ごきげん+5・体重+2
- **おかし**（無料）：ごきげん+10だが おなかは+3だけ・**体重+4** → おなかは満たせないのに ごはんの2倍太る（太りすぎると病気になりやすい）
- **あそぶ**（えさ1／途中のステージから始めるときだけ えさ10）：ごきげん+6・すなおさ+3・おなか-4・**体重-1**
- **病気**：一定確率でかかる → **おくすり（えさ20）** で治療

### がくしゅうログ（分析用・端末内）
出題アルゴリズムをさらに最適化するための記録。**すべて端末のlocalStorage内だけ**に保存し、外部へは一切送信しません。

- **1問こたえるごとに1行**記録。列は
  `ts, day, word, grade, mode, ok, ms, kind, lvBefore, ivlBefore, lateDays, spellMiss, viaDontKnow, streak, todayIdx, fast`
  （出題形式・正誤・かかった時間・そのとき新出か復習か・**回答直前のSRSレベルと間隔**・**期限からの遅れ日数**・スペル誤答回数・「わからない」使用・連続日数・その日の何問目）
- **日ごとに分けて保存**（書き込みが軽い・最大400日ぶん、あふれたら古い日から削除）
- せってい→データ に**その場の集計**を表示：新出/復習の正答率、形式別の正答率、**復習間隔（1/3/7/14/30/60日）ごとの正答率**、遅れ日数ごとの正答率、回答時間の中央値、よく勉強する時間帯
- **CSV / JSON でダウンロード**（CSVはExcel用にBOM付き。`= + - @` で始まる文字列セルは先頭に `'` を付けて無害化＝CSVインジェクション対策。JSONは列名・SRS間隔表も同梱）
- 「きろくを ぜんぶ けす」で削除可（育成の進捗は消えません）

> 分析の使いどころ：**間隔ごとの正答率**を見て、目標（一般に85〜90%）より低い間隔は伸ばしすぎ、高すぎる間隔はもっと伸ばせる、と判断できます。

### ミニゲーム①「だいぼうけん」（あそぶ・えさ1）
スーパーマリオ風の横スクロール・アクション。

- **操作はゲームパッド**（十字キー＋ABXY）：**◀▶で移動**、**X/Y＝ダッシュ**、**A/B＝ジャンプ**（本家SNES版と同じく2つずつ割り当て）
- **原作ゆずりの操作感**（初代スーパーマリオの数値設計をそのまま採用。1フレーム＝16pxタイル基準）：
  - **速度**…歩き 1.5px/F・走り 2.5px/F（原作と同じ比率 0.6）
  - **加速と摩擦は「毎フレーム一定量の たしひき」**…歩き +0.0369／走り +0.0556、手をはなすと −0.0369、**逆方向はブレーキ −0.1016（スキッド・砂煙つき）**
  - **可変ジャンプ**…上昇中にボタンを押している間だけ重力が弱い。**走行スピードで初速と重力の組が切り替わる**（初速 4.0／4.0／5.0、重力 0.125・0.117・0.156 ↔ 0.4375・0.375・0.5625）

  - 落下速度の上限 4.5px/F。空中は摩擦なしで慣性がのこる
- **ステージ全23面**：**手で設計した「パーツ」約30種**（かいだん・ピラミッド・高台・空中の足場道・浮きブロックのトンネル・1〜3タイルの土管・あな・敵の群れ など）をつなげて構成。進むほど幅がひろく（114→310列）、パーツの種類が増え、てきが増える（4→18）

## 画面構成

下部タブ（左右スワイプでも切替）：

- **そだてる**：キャラ・ステータス・お世話ボタン
- **がくしゅう**：デイリー目標・進化予告・おぼえた進捗・べんきょう開始
- **せってい**：ずかん／きせかえ／けいふ／たんご（単語一覧）／データ

## 構成（ファイル）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面テンプレート（Design Component）。表示時に React を読み込んで描画 |
| `support.js` | Design Component ランタイム（自動生成・編集しない） |
| `app.js` | アプリ本体のロジック（育成・クイズ・ゲーム・描画） |
| `words.js` | 英単語データ（英語・日本語・ふりがな・品詞）とバージョン番号 |
| `easy.js` | 「やさしいいみ」辞書 |
| `manifest.webmanifest` | PWA設定（ホーム画面追加用） |
| `icons/` | アプリアイコン |
| `characters/` | キャラクターのドット絵（36×36 PNG）。タマゴ・ベビー・キッズはオリジナル制作、ほか30種 |

> 表示時に React/ReactDOM を CDN（unpkg）から読み込むため、初回表示はネット接続が必要です。

## バージョン

ホーム画面の最下部に表示される `バージョン revXX` で、いま見ているバージョンを確認できます。
更新時は `words.js` 先頭の `APP_REV` を上げています。

## クレジット

- 英単語データ：[bangluutru/eiken-workbook](https://github.com/bangluutru/eiken-workbook)（出典 eiken-csv）
- ふりがな生成：[pykakasi](https://github.com/miurahr/pykakasi)
- キャラクターのドット絵・背景：すべてオリジナル制作

キャラクターのデザインはオリジナルで、既存キャラクターの複製は含みません。
